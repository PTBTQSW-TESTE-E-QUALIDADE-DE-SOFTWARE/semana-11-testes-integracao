# Semana 11. Integração: Testes de Integração

Criar casos de teste utilizando stubs (mocks)

Testar o método que realiza a persistência da classe Aluno em um banco de dados MongoDB.

O banco de dados ainda não foi implementado, portanto, você deverá utilizar um stub(mock) para substituir o banco de dados na sua classe de testes.

Código da aplicação exemplo: https://github.com/TQSA6/semana-11-aula.git


Você deverá construir:

1. Método "def test_salvarAluno(self):" da classe alunoTest.
2. Método "def salvar(self, conexao, colecao)" da classe AlunoClass.
